# Non-Functional Requirements (NFR)

## Performance

- **NFR-PERF-1:** Tail-снапшот транскрипта (главный + живые subагенты) не дольше 3 с на
  файлах до 50 МБ; интервал опроса по умолчанию 120–180 с.
- **NFR-PERF-2:** Вызовы факт-проверки `verify_claims.ts` локальные (файлы/БД) — до 2 с;
  live-проверка карточки не чаще 1 раза на цикл.
- **NFR-PERF-3:** Git-гейт и инвентаризация (standalone) не дольше 3 с на типовом дереве;
  диагностика `parallel-session-diag` — read-only, без блокирования сессии.
- **NFR-PERF-4:** Один ConPTY-процесс на воркера; без избыточного создания окон/процессов
  (memory `avoid-extra-windows-tabs-and-processes`).

## Security

- **NFR-SEC-1:** Адвизор НИКОГДА не пишет в JSONL воркера и не редактирует файлы, которые
  живой воркер сейчас пишет (single-writer); при конфликте — только read-only сверка.
- **NFR-SEC-2:** Промпты/снапшоты не содержат секретов (токены, куки Ozon); при capture в
  логи — redact. READ-ONLY для адвизора: диагностика «кто писал», сводка не мутируют файлы/состояние.
- **NFR-SEC-3:** Локал содержит только pid+cmdline (никаких секретов); аудит stale-восстановлений
  пишется в `.dev-pomogator/parallel-locks/` (gitignored). Override гейта `git add -A` логируется (escape-audit).
- **NFR-SEC-4:** Собственные процессы адвизора (ConPTY, daemon) подлежат graceful завершению.

## Reliability

- **NFR-REL-1:** При `claude --resume` того же session-id, пока жив другой писатель, —
  адвизор обязан сначала остановить старый процесс (Fail-closed). Гейт Fail-open в неизвестных
  деревьях (нет чужих транскриптов) — предупреждает, не блокирует.
- **NFR-REL-2:** Fail-open JSON-путей: повреждённая строка файла транскрипта пропускается,
  не роняя snapshot.
- **NFR-REL-3:** Адвизор различает «долгий думающий ход» (процесс жив) и «умер» (процесса нет);
  при смерти — саммари и вариант перезапуска. Stale-лок восстанавливается атомарно (wx) без гонки.
- **NFR-REL-4:** Инвентаризация устойчива к отсутствующим dashboard-процессам (standalone fallback).

## Usability

- **NFR-US-1:** Все инструменты доступны через скил `out-session-advisor` (allowed-tools покрывают
  Read/Write/Edit/Bash/Glob/Grep + верификационные вызовы).
- **NFR-US-2:** Команды/доклады адвизора — краткие саммари с evidence-путями, без пасты всего
  транскрипта; сводка диагностики человекочитаема (`repo | pid | вердикт | причина`).
- **NFR-US-3:** Winpty-путь определять автоматически (нет хардкода `%TEMP%`/`E:/repos/sales`);
  CLI-инструменты доступны и без dashboard (запуск одной командой).
- **NFR-US-4:** Правила `no-git-add-all-shared-tree`/`atomic-update-lock` остаются каноном —
  инструмент реализует их runtime-слоем, не дублирует разночтения.
