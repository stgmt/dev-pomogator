# Use Cases

## UC-1: Серая зона без токена → требование токена @feature15

1. Агент заканчивает ход прогресс/continuation-claim'ом, при этом в scope сессии есть открытая работа.
2. Хук доходит до серой зоны (gray-signal сработал), пытается позвать ИИ-судью.
3. `resolveEndpoint()===null` (нет токена) → судья не запускается.
4. **Хук возвращает block с видимым требованием подключить токен аипомогатора** (точные переменные + endpoint).
5. Юзер подключает токен → следующий стоп уже судится реально.

## UC-2: Серая зона с токеном → реальный судья @feature15

1. То же, но токен задан.
2. Судья запускается, решает block/approve по наблюдаемым фактам; ветка «нет токена» не трогается.

## UC-3: Заявлен результат без улики (happy path детекта)

1. Агент пишет вердикт-таблицу/«работает»/`[VERIFIED]`, но инструмент в ходе не запускал.
2. Хук блокирует «сначала прогони проверку».

## Edge cases

- `CLAIM_GATE_ENABLED=false`/`shadow` → не блокирует (UC-1/2/3 не применяются).
- Любая ошибка/нет transcript → approve (fail-open).
- Реально оффлайн без токена → после K киков FR-11 отпускает (не виснет).
